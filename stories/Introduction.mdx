# lit-timeline

A customizable timeline component built with Lit for displaying chronological events.

## Features

- **Horizontal, vertical, and list layouts**
- **CSS custom properties and parts for theming**
- **Automatic date ranges and chronological direct-child ordering**
- **One-sided mobile vertical layout below 600px**
- **ARIA labels, roving keyboard navigation, and list semantics**

## Installation

```bash
npm install lit-timeline
```

## Basic Usage

```html
<script type="module">
  import 'lit-timeline';
</script>

<timeline-component label="Project milestones">
  <timeline-event date="2024-03-15">
    <h3>Project Kick-off</h3>
    <p>The initial planning phase begins.</p>
  </timeline-event>
  <timeline-event date="2024-05-22" image-src="design.jpg" image-alt="Approved design mockups">
    <h3>Design Complete</h3>
    <p>Final designs approved by stakeholders.</p>
  </timeline-event>
</timeline-component>
```

## Components

### `<timeline-component>`

The main container positions direct event children on an axis or renders them as a list. Valid children are reordered chronologically. Invalid ranges warn and render no layout.

**Attributes:**

- `vertical` - Display vertically instead of horizontally
- `list` - Display a labelled list without an axis
- `start-year` - Override the start with an integer from 1 through 9999
- `end-year` - Override the end with an integer from 1 through 9999
- `label` - Accessible label; omitted or empty values fall back to `Timeline`

### `<timeline-event>`

Individual event cards are visible and focusable standalone; a parent timeline manages their layout and roving tabindex.

**Attributes:**

- `date` - Required strict canonical `YYYY-MM-DD` calendar date. Invalid, missing, or impossible dates are hidden and warn
- `image-src` - URL for the optional event image
- `image-alt` - Alternative text for a meaningful image; the default empty value makes it decorative

Dates are formatted in UTC. Axis-mode dates are visually hidden but available to assistive technology; list-mode dates are visible.

The component includes usable default card colors, border, radius, shadow, and typography. Themes and consumer styles can override them through the documented properties and parts.

## CSS Custom Properties

### Timeline Container

| Property                           | Default       | Description                                    |
| ---------------------------------- | ------------- | ---------------------------------------------- |
| `--timeline-axis-color`            | `#47476b`     | Main timeline axis color                       |
| `--timeline-axis-width`            | `2`           | Timeline axis stroke width                     |
| `--timeline-connector-color`       | `#47476b`     | Event connector color                          |
| `--timeline-connector-width`       | `2`           | Connector stroke width                         |
| `--timeline-dot-color`             | `#ff6b6b`     | Event dot color                                |
| `--timeline-dot-size`              | `5`           | Event dot radius                               |
| `--timeline-marker-color`          | `#a4a4c1`     | Date marker tick color                         |
| `--timeline-marker-text-color`     | `#a4a4c1`     | Date marker label color                        |
| `--timeline-marker-font-size`      | `0.9rem`      | Date marker label size                         |
| `--timeline-h-row-gap`             | `330px`       | Horizontal row stride (expands for tall cards) |
| `--timeline-v-column-gap`          | `100px`       | Vertical side gap                              |
| `--timeline-scrollbar-thumb-color` | `#47476b`     | Scrollbar thumb color                          |
| `--timeline-scrollbar-track-color` | `transparent` | Scrollbar track color                          |
| `--timeline-list-gap`              | `16px`        | List event gap                                 |
| `--timeline-list-padding`          | `20px`        | List container padding                         |
